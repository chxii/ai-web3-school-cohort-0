## 今日笔记：Cryptography 核心概念

### 1. 哈希（Hash）

- 任意长度输入 → 固定长度输出（如 256 bit）
- 不可逆，无法从输出推算输入
- 常用：SHA-256（比特币）、Keccak-256（以太坊）

### 2. 公私钥对

- **私钥（Private Key）**：随机生成的 256 bit 数字，绝对保密
- **公钥（Public Key）**：由私钥推导出来，可以公开
- 类比：私钥 = 保险柜密码，公钥 = 保险柜号码牌

### 3. 数字签名

- 用私钥对消息（或消息哈希）进行签名
- 任何持有公钥的人都可以验证签名是否有效
- 用途：授权交易、证明身份

### 4. 钱包地址

- 钱包地址 = 公钥的哈希（再经过一些处理）
- 不是公钥本身，而是公钥的"指纹"
- 例如：以太坊地址 = Keccak-256(公钥) 的后 20 bytes

### 5. Merkle Tree

- 用于高效验证大量数据完整性
- 常见于区块头（Block Header）、IPFS、去中心化存储

- 签名后的交易可以被任何人验证，但不能被伪造
