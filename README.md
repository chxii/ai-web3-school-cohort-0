# AI × Web3 School

> Personal learning journal and proof-of-work for AI × Web3 School.

## 关于这个项目

这是我在 [AI × Web3 School](https://aiweb3.school/zh/handbook/) 的个人学习仓库，用于记录每日学习、打卡、实验和项目实践。

## 核心资源

- [Handbook（学习手册）](https://aiweb3.school/zh/handbook/)
- [WCB 课程页面](https://web3career.build/zh/programs/AI-Web3-School)
- [WCB Learning](https://web3career.build/zh/programs/AI-Web3-School#tab=learning)
- [WCB Agent API 文档](https://web3career.build/llms.txt)

## 仓库结构

```
├── README.md              # 本文件
├── profile.md             # 个人学习画像
├── learning-plan.md       # 学习计划
├── daily/                 # 每日学习笔记 (YYYY-MM-DD.md)
├── tasks/                 # 任务记录
├── experiments/           # 实验和探索
├── handbook-feedback/     # Handbook 反馈与建议
├── hackathon/             # Hackathon 项目
├── submissions/          # 提交记录
└── templates/
    ├── daily-note.md      # 每日笔记模板
    └── task-note.md       # 任务笔记模板
```
